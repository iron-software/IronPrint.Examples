## IronPrint: A Comprehensive Cross-Platform Printing Tool

IronPrint is a dynamic tool that simplifies the process of printing documents across a variety of operating systems, such as Windows, macOS, Linux, Android, and iOS. Ideal for various .NET frameworks, IronPrint is perfectly compatible with Avalonia, MAUI, Xamarin (including Xamarin.iOS, Xamarin.Android, and Xamarin.Forms), and WPF.

### Using the `Print` Method

To dispatch documents to the default printer, employ the `Print` method. This function allows for precise customization of printer preferences through the **`PrintSettings`** object.
